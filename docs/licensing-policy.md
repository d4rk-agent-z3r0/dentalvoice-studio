### What this grants

Anyone may use, copy, modify, merge, publish, distribute, sublicense and sell copies of the
project's original code, provided the copyright notice and permission notice are kept. The
software is provided without warranty. Unlike Apache-2.0, MIT contains no express patent grant;
the owner chose MIT knowing this.

The MIT licence covers **only the project's original material**. Third-party dependencies, tools
and assets remain under their own licences (see `THIRD_PARTY_NOTICES.md` and
`docs/license-audit.md`) and are not relicensed by this project.

## Source file marking

Original source files carry [REUSE](https://reuse.software/)-style headers:

```
SPDX-FileCopyrightText: 2026 Siddharth Majhi
SPDX-License-Identifier: MIT
```

`scripts/add_spdx_headers.py` adds them idempotently; `--check` runs in `make lint` and CI. Files
deliberately left unmarked:

| Kind | Examples | Why |
|---|---|---|
| Template-derived | `frontend/eslint.config.mjs`, `frontend/next.config.ts`, `frontend/pnpm-workspace.yaml` | Generated by create-next-app (MIT, Vercel); see `docs/ownership-and-provenance.md` |
| Machine-generated | `uv.lock`, `pnpm-lock.yaml`, `frontend/AGENTS.md` | Tool output, not authored |
| Formats without comments | `*.json`, empty `__init__.py` | Covered by the repository `LICENSE` |
| Third-party files | none vendored yet | Their existing notices are preserved, never overwritten |

## Rules

| Rule | Detail |
|---|---|
| Owner approval | The project licence changes only with the owner's explicit approval, recorded in the history below |
| No automatic changes | Refactoring, dependency updates and tooling never change the project licence |
| Attribution | Third-party copyright notices and attribution are never removed |
| Dependencies | New dependencies must pass the licence policy (see `docs/license-audit.md`); unknown licences are escalated for manual review, never assumed permissive |
| Assets | No third-party or AI-generated asset is committed until its source and redistribution terms are recorded in `docs/ownership-and-provenance.md` |
| Prior distributions | A future licence change does not recall copies already distributed under an earlier licence |
